My core engineering identity centers on building **LLM-powered agentic architectures**: multi-agent orchestration, tool-calling pipelines, retrieval-augmented generation (RAG), and custom LLM infrastructure built from first principles.

##  Featured Projects

<details open>
<summary><b>🔗 LLM Router</b></summary>
<br/>

An intelligent routing system that dynamically directs incoming queries to the most suitable LLM or specialized agent based on task complexity, cost, and latency constraints — enabling efficient, multi-model agentic pipelines.

| Category | Details |
|---|---|
| **Stack** | Python, LangChain, LangGraph, FastAPI |
| **Scale** | Multi-model routing across specialized agent nodes |
| **Performance** | Optimized for low-latency inference selection |
| **Security** | API key isolation, request validation layers |
| **Impact** | Reduces inference cost while preserving output quality |
| **Repository** | [github.com/anuj667/LLM_Router](https://github.com/anuj667/LLM_Router) |

This project reflects core agentic engineering principles — decision-making logic sits above the model layer, allowing the system to reason about *which* model should handle a task rather than relying on a single static endpoint.

</details>

<br/>

<details>
<summary><b>🔗 LLM From Scratch</b></summary>
<br/>

A ground-up implementation of a transformer-based large language model, built without high-level abstraction libraries to demonstrate deep understanding of attention mechanisms, tokenization, and autoregressive training.

| Category | Details |
|---|---|
| **Stack** | Python, PyTorch, NumPy |
| **Scale** | Custom transformer architecture trained on curated corpora |
| **Performance** | Benchmarked against baseline perplexity metrics |
| **Security** | Sandbox-isolated training environment |
| **Impact** | Demonstrates first-principles mastery of LLM architecture |
| **Repository** | [github.com/anuj667/LLM-from-scratch](https://github.com/anuj667/LLM-from-scratch) |

Built to internalize the mechanics behind modern LLMs — from self-attention and positional encoding to the training loop itself — rather than treating them as black-box APIs.

</details>
